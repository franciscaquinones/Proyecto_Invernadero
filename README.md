Para ejecutar el proyecto localmente se necesita el programa visual studio code y git
Primero se necesita clonar el proyecto en su computador entonces al apretar en el boton verde <>code puede obtener el link del proyecto, una vez copiado en el programa visual studio code se abre una nueva terminal y escriba git clone y copia el link del proyecto
despues para entrar en el proyecto hacer cd proyecto_invernadero
luego en visual en la seccion de archivos selecciona abrir carpeta y ahi abre el proyecto_invernadero
para ejecutar la pagina el programa visual studio code necesita tener una extension llamada live server, para obtener esta extension en la pantalla de visual debe apretar la combinacion de botones ctrl + shift + xy en la barra de busqueda escribir live server e instalarlo
una vez instalado haga click derecho en el archivo index.html y seleccione la opcion de abrir con live server y ahi el navegador abrirá automaticamente la página en su computador
