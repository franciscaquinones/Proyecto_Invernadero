Conócenos

Bienvenido a Arklay Botanics, este es un proyecto enfocado en facilitar el cuidado y seguimiento de distintos tipos de cultivos a traves del uso de la tecnología. Con estas herramientas se planea optimizar el crecimiento de las plantas para mejorar su calidad gracias al constante monitoreo de estas.

Nuestros cultivos

Los invernaderos cuentan con una gran variedad de opciones para cultivar desde plantas ornamentales, medicinales e incluso alimentos. Como cada cultivo necesita un cuidado y condiciones ambientales diferentes, se realiza un seguimiento constante del estado de cada uno de ellos, de esta forma se aseguran las óptimas condiciones para cada cultivo.

¿Quienes somos?

Arklay Botanics nace como una iniciativa orientada a mejorar la gestion de lso invernaderos a través del uso de herramientas tecnológicas. Se busca crear un entorno que sea amigable y facilite la administración de los cultivos al supervisar los sensores para cada cultivo. De esta forma es posible consultar la información de una manera clara y accesible. Como equipo creemos que la tecnolgía es el mejor aliado para comprender y cuidar mejor los cultivos.

Desarrolladores

Arklay Botanics fue desarrollado por Francisca Quiñones y Oscar Oviedo, ambos estudiantes de la Universidad Diego Portales. En este proyecto se coloca a prueba la capacidad de los desarrolladores para aplicar sus conocimientos en el desarrollo web para construir una plataforma qwue permita a los usuarios gestionar y supervisar sus cultivos de manera eficiente.
